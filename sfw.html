STAGE 2Where should it go?

GitHub mode keeps everything in one repository and installs Ruffle there for you. HTML only gives you a single file.

Ruffle is gzip-compressed inside the page and its splash logo is switched off. With both boxes as they are, the file makes no outside requests. Untick the first box to always use a CDN and get a tiny file.

Create a classic token with the repo scope. It is only ever sent to api.github.com.

You get a small HTML file that has the game's own code inside and loads the large files from your repository. If the repository does not exist it is created, Ruffle goes in ruffle/ only when missing, and each SWF goes in games/<name>/. The repository has to stay public for the links to work. GitHub Pages is not used: the HTML reads the repository's raw files and is pinned to the commit made during this conversion, so later pushes can't break it.
