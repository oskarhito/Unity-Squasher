    Files go in a public repo with that name (created if missing), one folder per game. Anyone with the link can download them, and the game needs internet plus that repo to keep existing.

    🧠 Good to know

    Works with Unity 2020+ builds (files named *.loader.js, *.framework.js, *.data, *.wasm). Files stay gzip-compressed inside the output (uncompressed builds get compressed for you), so the result is much smaller than the raw build. Brotli (.br) isn't supported by browsers' built-in tools, so rebuild with Compression Format set to Gzip or Disabled.

    Everything is base64-encoded inside the file. Don't paste the code into websites, upload the .html file instead, since a file this big can crash text boxes. If your build has a StreamingAssets folder, it gets packed in too and handed to Unity on demand. Big StreamingAssets make the file larger and the game slower to start.

    🐙 Attach to GitHub uploads the heavy files (framework, data, wasm, StreamingAssets) to a public repo on your account and leaves only a tiny loader in the HTML. The game then downloads them when it starts, so it needs internet.

    Open this page with an internet connection once, since it pulls the zip reader from cdnjs.
