    🧠 Good to know

    Works with Unity 2020+ builds (files named *.loader.js, *.framework.js, *.data, *.wasm). Gzip (.gz) builds are unpacked for you. Brotli (.br) isn't supported by browsers' built-in tools, so rebuild with Compression Format set to Gzip or Disabled.

    Everything is base64-encoded inside the file, so expect it to be about a third bigger than your build. Games using a StreamingAssets folder will need those assets inlined separately, they can't be loaded from a single file.
